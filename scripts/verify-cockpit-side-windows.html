Cockpit side-window A/B verification

Start Vite at the repository root, open this page and run once the simulator is ready. The page enables developer mode, enters the cockpit shadow demo and loads the interior itself. For each sun direction it renders the same frame three times: side-window depth proxies cut (shipped), proxies closed, and deck sun off. Floods are driven by the baked light transfer (#163), not by aperture admittance, so only direct deck sun can differ. Keep the Browser window visible: a hidden page pauses animation frames.

Ready when the simulator has loaded.
