# 시화방조제와 대부도 주변 지형

인천공항을 선택하면 기존 12km 공항 지형에 **50km × 50km** 지역 메시가 연결됩니다.
시화방조제의 해안선과 대부황금로, 시화호 수면, 조력발전소, 시화나래 달전망대,
방아머리해변을 포함합니다. 인천공항에서 남동쪽으로 약 20km 떨어진 지역입니다.
기존 활주로·유도로·주기장 원본은 수정하지 않습니다. `/incheon.html`의 이전 단계
비교 화면은 기존 범위를 유지하고, 이 확장은 메인 시뮬레이터의 인천 환경에 적용됩니다.

## 자료와 표현 범위

- `public/scenery/incheon/sihwa/sources/`: 수신 시각, 쿼리/URL, 원본 SHA-256을
  보관한 OSM 스냅샷 세 개. ODbL-1.0이며 기존 OSM 저작자 표시를 공유합니다.
- 해안선 156개 way를 방향에 따라 육지/바다로 구성하고, 시화호 relation/4860085의
  외곽·내곽 링을 연결해 호수를 뺍니다. 누락된 node나 열린 링을 임의로 닫지 않습니다.
- 발전소 way/409163571, 공원 way/1038767377, 관리단 부지 way/1038767385,
  해변 way/196292129 및 현장 건물 다섯 개의 실제 지도 윤곽을 사용합니다.
  도로는 `대부황금로`로 태그된 way를 추출합니다. 지도 윤곽은 측량 자료가 아닙니다.
- 고도는 기존 공항과 같은 Copernicus GLO-30 N37/E126 타일입니다. 원본 SHA-256은
  `f530dd28308ecd6c5ceb0405dc1ffb7113bcafdec30d023de50f16dc433a274f`입니다.
  EGM2008 정표고를 사용하며 바다와 호수는 모두 모델 수면 Y=0입니다. 조석은 없습니다.
- [공식 관광 안내서](https://tong.visitkorea.or.kr/ktobiz/upload/accessible_tour_20.pdf)의
  달전망대 높이 75m와 [K-water 자료](https://www.kwater.or.kr/news/busiCardList.do?brdId=KO74&pageNo=9&seq=132328)의
  발전기 10기·총 254MW를 반영합니다. 전망대 외형은
  [경기문화재단 사진](https://ggc.ggcf.kr/en/p/5a6b426bafeca47471384c56)을 참고했습니다.
  사진은 게임 자산으로 재배포하지 않습니다.

시설 외관은 원형 전망층·기둥과 발전시설을 알아볼 수 있도록 만든 절차적 경량 모델입니다.
건물별 설계도·수문 구조·실측 높이 전체를 복원한 것은 아닙니다. 발전시설·공원 부지의
DSM 지붕 흔적은 주변 지면의 하위 20% 표고로 평탄화하고 30m에서 자연 고도로 복귀합니다.
도로 폭 8.5m 및 교량 최소 상판 높이 4.5m는 모델값입니다. OSM `bridge=yes` 구간만
수면 위로 연결하며, 호수와 바다의 열린 부분을 가상의 육지로 메우지 않습니다.

일반 육지의 100m 셀을 실제 해안선·호수 경계로 잘라 삼각분할합니다. 모래와 도로도
같은 지면 삼각형으로 잘라 2.5cm/6cm만 띄우므로 독립적인 평면이 언덕을 관통하지 않습니다.
일반 육지 색상은 기존 공항과 같은 예시용 지면 표현이며 위성사진·실제 토지피복은 아닙니다.
주변 도시의 건물 전체나 발전소 운전·수위 변화는 포함하지 않습니다.

## 지면 공유와 비용

지역 육지는 112,795개 정점·195,881개 삼각형이며 위치/인덱스 파일은 약 3.7MB입니다.
렌더링은 지면 한 메시와 색상별 병합 시설 메시를 사용합니다. 런타임 GIS, 외부 지도 호출,
추가 광원, 프레임별 모델 생성은 없습니다. 지면 접지는 100m 공간 버킷으로 후보 삼각형을
찾아 화면에 그린 평면을 그대로 보간합니다. 교량도 표시한 상판 삼각형을 접지에 공유합니다.
시설 충돌은 기존 공항의 장애물 판정에 연결하며, 전망층 아래의 빈 공간을 채우지 않습니다.

기존 공항 내부 해안선과 새 해안선의 면적 차이는 0m²입니다. 공항의 인위적인 6km
클리핑 경계만 1m 바깥으로 연장해 육지 가장자리의 잘못된 수면 판정을 제거합니다.
지역 메시의 공항 경계 정점은 기존 25m 그리드에 맞춰 분할하고 동일한 높이를 사용합니다.
기존 공항 내부의 자연 고도와 포장 평탄화는 유지합니다.

## 재생성 및 확인

Python 3.12와 `scripts/terrain/incheon-requirements.txt`의 고정 의존성을 사용합니다.
DEM은 메타데이터의 공개 URL에서 받아 다음처럼 전달합니다. OSM 원본은 이미 저장되어
있으므로 재생성에 실시간 Overpass 쿼리는 필요하지 않습니다.

```sh
python scripts/terrain/build-sihwa.py --dem /path/to/copernicus-n37-e126.tif
node --test tests/sihwaRegion.test.js
npm run check
npm test
npm run build
npm run dev -- --host 127.0.0.1 --port 5288
APP_URL=http://127.0.0.1:5288/ chrome-session --project flight3d node scripts/verify-sihwa.mjs
```

`verify-sihwa.html`은 공항 로더와 수면을 사용한 개발용 조망 화면입니다. 검증 스크립트는
발전소·전망대·해변·방조제 조망 네 장과 브라우저 오류, 삼각형 수/드로콜을 기록합니다.
이어서 메인 시뮬레이터에서 인천 환경을 로드하고 활주로에서 10초 접지, 교량 표면 높이,
전망대 기둥·전망층 충돌과 빈 공간을 검사합니다. FPS/전체 비행 성능을 보장하는 벤치마크는 아닙니다.
