# 한강 교량 실측 조사표 (issue #396 1단계)

확인일: 2026-11-02. 게임 좌표 변환 전의 원자료입니다. 수치마다 출처 기호를 붙였고,
기호가 없는 값은 쓰지 않습니다.

게임에는 4절의 **안 B(서강 → 마포 → 한강대교, 실제 순서와 간격)**를 적용했고, 주경간은
실제 최대 경간으로 좁혔습니다. 적용한 값과 게임용으로 정한 값은 [neon-river.md](neon-river.md#bridges-396)에 있습니다.

## 3. 높이 기준

- 한강대교 수위관측소 영점표고: **EL 2.070m** (2009년 이후) **P**. 따라서 해발고 = 2.070m + 수위표 값.
- 한강대교 지점 홍수 기준 (수위표 값): 주의 8.5m, 경계 10.5m, 심각 13.3m. 기록 최고 11.76m (1925) **N**.
- 잠수교 통제 기준 (잠수교 수위표 값): 보행 5.5m, 차량 6.2m. 6.5m부터 노면 침수 **N**. 잠수교 수위표의 영점표고는 미확인.
- **평상시 수위는 확보하지 못했습니다.** 한강홍수통제소 수위 자료로 한강대교 지점 연간 중앙값을 따로 구해야 합니다.
- 교량 높이(상판 표고, 형하고)는 공개 자료에서 찾지 못했습니다. 설계도서나 서울시 교량안전과(02-2133-1943)에 문의해야 합니다. 이 값이 없으면 실측 재현이라고 할 수 없습니다.

## 4. 위치 관계와 게임 배치

교량 사이 직선거리 (O 중심점 기준):

| 구간 | 거리 |
|---|---|
| 월드컵 → 서강 | 4.1km |
| 서강 → 마포 | 1.1km |
| 마포 → 한강대교 | 2.6km |
| 한강대교 → 동작 | 2.2km |
| 동작 → 반포 | 1.4km |
| 반포 → 올림픽 | 9.8km |

현재 코스는 교량 3개를 1.7–1.8km 간격으로 두고 강을 남북 방향(-Z)으로 놓았습니다. 실제 한강은
남북이 아니라 동서로 흐르고, 한강대교 부근에서 강 방향은 대략 117°/297°입니다.

- **안 A: 형식 우선.** 한강대교 / 올림픽대교 / 반포대교를 쓰되, 거리와 순서는 게임에 맞게 바꿉니다.
  올림픽대교가 9.8km 떨어져 있어서 배치는 실측이 아닙니다.
- **안 B: 지리 우선.** 서강대교(닐슨 아치) → 마포대교(거더) → 한강대교(타이드 아치, 노들섬)를
  실제 순서로 3.7km 안에 둡니다. 대신 `tower` 형식이 빠집니다.

## 5. 현재 게임 치수와 비교

현재 절차적 교량 (`src/config/hangangCourse.js`, main 기준):

- 상판 중심 높이 38m, 두께 4m, 폭 22m, 길이 1,200m
- 교각 x = ±55, ±150, ±350, ±550m. 중앙 통로 폭 100m, 높이 34m

비교:

- 실제 최대 경간은 거더교 30–70m, 아치교 63.5–150m입니다. 사장교만 225–300m입니다.
  현재 게임의 중앙 통로(교각 사이 110m)는 한강대교·반포대교보다 넓습니다.
- C172 날개폭은 11.0m입니다. 잠수교 30m 경간은 양쪽 여유가 약 9.5m씩입니다.
- 형하고를 모르기 때문에, 현재 34m 통로 높이가 실제보다 얼마나 높은지는 판단할 수 없습니다.

**결론:** 형하고와 상판 표고를 확보하기 전에는 모든 후보를 "모티브"로 표기합니다
(이슈 1단계 규칙: 오차가 C172 통과 여유보다 크면 실측 재현이라고 하지 않음).
이 표에서 바로 쓸 수 있는 값은 형식, 폭, 최대 경간, 교축 방향입니다.

## 미확인 항목

- 교량별 상판 표고, 형하고, 거더 높이, 교각 간격 전체 목록
- 한강대교 지점 평상시 수위 (연간 중앙값)
- 잠수교 수위표 영점표고
- 올림픽대교 최대 경간 300m가 주경간 하나인지, 사장교 구간 전체인지 (W에는 경간 값이 없음)
- 서강대교 "운행높이 21m"가 무엇을 잰 값인지
- S 자료의 이용허락 조건
