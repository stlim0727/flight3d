# 시화 해안 관광 데모

로비에서 **인천공항 → 데모 → 시화 해안 둘러보기**를 선택합니다. B737-800,
C172, F-16 모두 지원합니다. 기존 B737 출발 시나리오와 C172 공항 투어는 유지하며,
이전 데모 선택값이 없을 때의 기본값도 변경하지 않습니다. F-16의 인천 데모는
이번 관광 코스를 사용하고 기존 루클라 데모들도 유지합니다.

공항에서의 이륙·착륙을 포함하는 코스가 아니라 방조제 인근의 공중 출발 코스입니다.
방조제 → 조력발전소·시화나래 달전망대 → 방아머리해변 → 서해 해상 선회 → 귀환의
순서로 비행합니다. 시작 위치를 한 번 설정한 뒤에는 실제 조종 입력과 물리 엔진으로
비행합니다. 경로를 따라 기체 위치를 애니메이션하거나 다음 구간으로 옮기지 않습니다.

| 기종 | 목표 IAS | 기본 고도 | 해상 선회 반경 |
| --- | --- | --- | --- |
| C172 | 90kt | 300m | 950m |
| B737-800 | 205kt | 550m | 2,500m |
| F-16 | 260kt | 650m | 3,400m |

F-16은 현재 엔진 모델의 저속 추력을 상쇄하기 위해 모델 에어브레이크를 80% 적용하며,
해당 구성의 트림과 고속 입력 감쇠를 반영한 제어를 사용합니다. 완료·중단 시에도
에어브레이크의 물리 구성을 유지합니다.

고도는 모델 해수면 기준입니다. 경로는 시화 지형 자산의 발전소·전망대·해변 좌표에서
만든 관광용 경로이며 실제 항공 교통 절차가 아닙니다. 시설에서 옆으로 떨어져 통과하고
기종별 반경으로 해상에서 선회합니다. 지형 전방을 확인해 고도를 보정하며 일반 충돌
검사를 끄지 않습니다. 같은 출발 구간으로 돌아온 뒤 1.2km 직선 구간에서 날개를
수평에 가깝게 정리하고 현재 위치·속도·추력을 유지한 채 수동 조종으로 인계합니다.

네 장소를 실제로 통과하고 귀환·이탈 구간까지 비행해야 완료됩니다. 시간만 지나서는
완료되지 않습니다. 허용 경로를 벗어나거나 높이 여유가 부족하면 실패로 기록하고 수동
조종으로 인계합니다. Esc로 중단하고 P로 다시 시작할 수 있습니다. 사용자가 선택한
카메라는 관광 단계 전환 후에도 유지됩니다.

지형과 시설의 출처 및 모델 근사 범위는 [시화 지역 확장](incheon-sihwa.md)을 참고하세요.
병합된 시화 지형 PR #279를 기반으로 하며 기존 주기 항공기·포장 겹침 수정·
F-16 협곡 데모를 보존합니다.

검증 도구:

```sh
node --test tests/sihwaTour.test.js
npm run check
npm test
npm run build
npm run dev -- --host 127.0.0.1 --port 5289
APP_URL=http://127.0.0.1:5289/ chrome-session --project flight3d node scripts/verify-sihwa-demo.mjs
```

브라우저 도구는 실제 메인 시뮬레이터에서 세 기종의 전체 비행을 진행하고 시설 통과,
충돌·고도 여유, 카메라 수동 선택과 Esc 중단, 완료 후 추력·조종권 인계를 검사합니다.
검증 중 실시간 프레임의 물리만 고정하고 `stepSimulation`으로 같은 물리 스텝을
실행합니다. 이는 실제 FPS나 항로 운항 인증을 위한 검증이 아닙니다.

검증 결과는 [실제 비행 기록](../../review-artifacts/sihwa-demo/README.md)에 있습니다.
전체 809개 Node 테스트, 구문 검사, 프로덕션 빌드와 세 기종의 전체 브라우저 비행을
통과했습니다. 렌더링 FPS는 측정하지 않았습니다.
