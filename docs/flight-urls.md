# Flight URL reference

All 48 supported aircraft, terrain, and scenario combinations are listed below.
Each link starts the selected flight directly.

- [Flight3d](https://stlim0727.github.io/flight3d/)
- [Filterable URL directory](https://stlim0727.github.io/flight3d/flights.html)
- [README](../README.md#direct-flight-urls)

## Parameters

| Parameter | Values |
| --- | --- |
| `aircraft` | `B738` (Boeing 737-800), `C172` (Cessna 172), `F16` (F-16) |
| `terrain` | `coastal`, `lukla`, `incheon`, `neon`, `hangang` |
| `scenario` | `runway`, `approach`, `cruise`, `cliff`, `demo`, `hangang` |

Values are case sensitive. URL parameters override saved preferences; omitted
parameters use saved choices. Invalid values or unavailable scenarios fall back
to the existing defaults. Hangang always uses C172 and the Hangang scenario.
Cliff takeoff is available only at Lukla. Coastal F-16 and all Neon City aircraft
do not support demo. The tables include only supported combinations, so their
links do not require a fallback. Browser audio permission rules still apply.
